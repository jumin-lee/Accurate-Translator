# `entries.json` 형식

사이트의 모든 내용은 `data/entries.json` 하나에서 나옵니다. 최상위는 항목 배열입니다.

새 항목은 Claude Code 대화에서 "이거 추가해줘" 라고 하면 이 형식에 맞춰 덧붙습니다.
직접 손으로 넣어도 됩니다.

## 항목 하나

```jsonc
{
  "id": "ko-tikkeul-moa",        // 파일 안에서 유일한 값. 로마자+하이픈.
  "added": "2026-09-17",         // 추가한 날짜 (YYYY-MM-DD)
  "kind": "idiom",               // idiom | phrase | word
  "ko": "티끌 모아 태산",          // 한국어 쪽
  "romanization": "tikkeul moa taesan",  // ko 의 로마자 발음. 없으면 "".
  "sv": "Många bäckar små blir en stor å.",  // 스웨덴어 쪽 (자연스러운 표현)
  "literal_sv": "Damm samlat blir ett stort berg.",  // 직역. 없으면 "".
  "meaning": "작은 것도 모이면 큰 것이 된다.",  // 한국어 뜻풀이
  "words": [                     // sv 에 쓰인 낱말을 나온 순서대로
    {
      "surface": "bäckar",       // 문장에 나타난 그대로
      "base": "bäck",            // 사전형. 같으면 같은 값.
      "pos": "명사 (en-단어, 복수 -ar)",  // 품사. 명사는 성과 복수형, 동사는 시제를 함께.
      "meaning": "시내, 개울",     // 이 문맥에서의 뜻
      "note": ""                 // 덧붙일 말. 없으면 "".
    }
  ],
  "notes": ["문법 노트 배열. 없으면 []."],
  "examples": [{ "sv": "...", "ko": "..." }],  // 예문 쌍. 없으면 [].
  "equivalent": {                // 뜻이 통하는 상대 언어의 고유 표현
    "sv": "", "literal": "", "note": ""   // 없으면 sv 를 "" 로.
  },
  "tags": ["속담"]               // 분류용. 자유롭게.
}
```

## 규칙

- `words` 는 **`sv` 에 쓰인 낱말**을 담습니다. 한국어 낱말이 아닙니다.
  사이트의 단어장이 이걸 `base` 기준으로 모아 보여 주기 때문입니다.
- 관용구처럼 굳어진 덩어리는 낱말로 쪼개지 말고 한 항목으로 두고 `note` 에 밝힙니다.
- `kind`
  - `idiom` — 속담·관용구. **오늘의 숙어**가 여기서만 고릅니다.
  - `phrase` — 일상 표현, 문장
  - `word` — 낱말 하나
- 빈 값은 키를 빼지 말고 `""` 또는 `[]` 로 둡니다. 화면 쪽에서 분기가 단순해집니다.
- 항목이 수천 개로 늘면 그때 파일을 쪼개면 됩니다. 그 전까지는 한 파일로 충분합니다.

## 품질에 관하여

스웨덴어는 원어민 검수를 거치지 않았습니다. 학습용으로 쓰시되,
중요한 자리에 쓸 문장은 따로 확인하시는 편이 좋습니다.
