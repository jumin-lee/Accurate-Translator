사용량
API 키가 아직 등록되지 않았습니다.

이 사이트는 서버 없이 브라우저에서 바로 Claude API를 호출합니다. 번역을 사용하려면 본인의 Anthropic API 키를 등록해 주세요. 키는 이 브라우저에만 저장되고 다른 곳으로 전송되지 않습니다.

오늘의 숙어

번역기

한국어나 스웨덴어를 입력하면 번역문과 함께 단어별 뜻을 풀어 드립니다.

Ctrl+Enter 로도 번역할 수 있습니다. 0자

지난 숙어

이 브라우저에 저장된 기록입니다.

브라우저에서 직접 Claude API를 호출합니다. API 키는 이 기기의 localStorage에만 저장됩니다.

설정

platform.claude.com 에서 발급할 수 있습니다. 지출 한도는 Settings → Workspaces 에서 거세요.

보안 안내

이 사이트에는 서버가 없어서 키가 브라우저 안에서 그대로 쓰입니다. 이 기기를 쓰는 사람은 누구나 개발자 도구로 키를 볼 수 있으니, 공용 컴퓨터에서는 쓰지 마시고 사용량 한도를 걸어 둔 전용 키를 권장합니다.

꼼꼼할수록 설명이 자세해지지만 응답이 느려지고 비용이 늘어납니다.
